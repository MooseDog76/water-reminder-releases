# water-reminder-releases
Installers (and updates) for **InThirst** - called Acquado.com - App from 0.1.35 to 0.1.56, and Water Reminder before.
Website: inthirst.com. Feedback: feedback@inthirst.com (or Send feedback in the app's About).

The newest version: https://github.com/MooseDog76/water-reminder-releases/releases/latest

**Never attach work files, or screenshots showing work, to an issue here - this page is public.** Security problems:
see `SECURITY.md`.

A reminder, not medical advice.

`notices.json` is read by the app with each update check. Versions listed in `bad` are never installed. A `notice`
({id, date, title, words, todo, from, to}) is shown once, at the next start, to people on those versions. Leave it as
`{"bad": [], "notice": null}` when there's nothing to say.
